# Acessa-
**Acessaí** é uma plataforma de acessibilidade que permite a pessoas com deficiência planejarem seus deslocamentos com mais segurança e autonomia. O sistema apresenta informações sobre a acessibilidade do destino e das rotas, considerando recursos como rampas, calçadas, transporte e outros obstáculos que possam impactar o trajeto.
